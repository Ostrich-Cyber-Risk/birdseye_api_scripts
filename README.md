# birdseye_api_scripts
A collection of scripts to run against the public birdseye api

| Script                                           | What it does                                              |
|--------------------------------------------------|-----------------------------------------------------------|
| [setTargets](setTargets)                         | Reads and writes assessment targets in bulk through a CSV |
| [exportAssessmentStatus](exportAssessmentStatus) | Exports assessment status and scores to a CSV             |
| [createScenarioFamilies](createScenarioFamilies) | Creates scenario families from a CSV                      |

Each folder has its own setup steps and pinned requirements.
